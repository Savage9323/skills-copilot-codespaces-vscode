# Resource Policy

Treat hosted minutes, cloud credits, free-tier allowances, student benefits, API quotas, and storage/compute allowances as shared portfolio resources.

## Priority

1. local workstation
2. included/student-entitled software
3. verified always-free/free-tier services
4. existing zero-incremental-cost cloud
5. authorized self-hosted infrastructure
6. hosted CI/build credits
7. paid resources

Before selecting Azure or another cloud service, verify the current offer, actual subscription/tenant eligibility, region, quota, paid threshold, and behavior at quota exhaustion.

Do not automatically move an exhausted workload to another limited-credit platform.
