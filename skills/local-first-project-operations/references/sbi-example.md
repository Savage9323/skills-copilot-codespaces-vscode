# Student Benefits Intelligence Example

Validated pattern:
- Next.js/TypeScript
- Supabase/PostgreSQL
- Docker/GHCR
- Azure Container Apps
- Azure DevOps
- WSL2 Ubuntu
- Ollama/NVIDIA GPU
- optional Amazon Creators API

When hosted Azure DevOps minutes are unavailable, keep normal CI configuration for future reset, run authoritative local gates, deploy the current main commit through the version-controlled local deployment script, use immutable SHA-tagged GHCR images, verify Azure origin/custom domain/health revision, and roll back automatically on verification failure.

Amazon OAuth success and Associates eligibility are separate. An authenticated AssociateNotEligible response is an external warning when the core application does not depend on Amazon product access.
